# Ассемблер учебной виртуальной машины (УВМ)

CLI-приложение для разбора текстового представления программ на языке ассемблера УВМ и трансляции во внутреннее представление. Реализовано на Free Pascal.

## Сборка и запуск

### Требования
* Компилятор `fpc` (Free Pascal Compiler 3.2+)
* Утилита `make` (опционально)

### Сборка через Makefile
```bash
make
```
Для очистки объектных файлов:
```bash
make clean-obj
```

### Ручная сборка
```bash
fpc -O2 EduVM.pas -o EduVM
```

### Аргументы командной строки
```bash
./EduVM <input_file> <output_file> [test]
```
* `<input_file>` — путь к исходному текстовому файлу с программой.
* `<output_file>` — путь к выходному двоичному файлу.
* `test` — режим тестирования (выводит промежуточное представление в стандартный поток вывода в формате полей `A` и `B`).

## Спецификация языка ассемблера

### Синтаксис
* Каждая инструкция располагается на отдельной строке.
* Разделителями между мнемоникой и операндом служат пробелы (`0x20`) или символы табуляции (`0x09`).
* Пустые строки игнорируются.
* Операнды задаются целыми неотрицательными десятичными числами.

### Система команд

| Мнемоника | Синтаксис | Опкод (`A`) | Размер (байт) | Описание |
| :--- | :--- | :---: | :---: | :--- |
| `push` | `push <B>` | `6` | `4` | Загрузка константы `B` на вершину стека. |
| `lods` | `lods` | `3` | `1` | Чтение значения из памяти по адресу с вершины стека и помещение результата на стек. |
| `stos` | `stos <B>` | `1` | `3` | Снятие значения с вершины стека и запись в память по адресу `B`. |
| `xor` | `xor <B>` | `4` | `2` | Побитовое исключающее «ИЛИ» между значением в памяти (по адресу с вершины стека) и вторым элементом стека; запись результата в память по адресу (третий элемент стека + `B`). |

## Тестирование

### Пример входного файла (`test_spec.asm`)
```text
push 540
lods
stos 100
xor 12
```

### Запуск в режиме тестирования
```bash
./bin/EduVM test_spec.asm out.bin test
```

### Результат вывода
```text
A=6, B=540
A=3
A=1, B=100
A=4, B=12
```

## Обработка ошибок
При обнаружении синтаксических или семантических ошибок транслятор завершает работу с кодом возврата `1` и выводит диагностическое сообщение с указанием номера строки:
* Неизвестная мнемоника команды.
* Отсутствие обязательного операнда или передача лишнего операнда.
* Некорректный формат операнда или недопустимый символ.
* Ошибки открытия/создания файлов и неверные аргументы командной строки.
